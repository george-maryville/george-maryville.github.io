# Portfolio Template

A starter portfolio site for Maryville Computer Science students. Copy it, make it yours, and publish it free with GitHub Pages.

## Set it up (about 10 minutes)

1. Click **Use this template → Create a new repository**.
2. **Name the repo `your-username.github.io`** (use your own GitHub username). This exact name makes GitHub serve it as your personal site.
3. In the new repo, go to **Settings → Pages** and set **Source: Deploy from a branch**, branch **`main`**, folder **`/ (root)`**. Save.
4. Wait a minute, then visit **https://your-username.github.io** — your site is live.

## Make it yours

Everything you need to change is marked with an `EDIT:` comment.

- **`index.html`** — your name, tagline, links, about text, and project cards.
- **`style.css`** — change `--accent` and `--ink` at the very top to re-theme the whole site.
- **`resume.pdf`** — drop your résumé in the repo root so the Résumé link works.
- **`assets/`** — put project screenshots here (`~1200×750px` looks best).

## Add a project

In `index.html`, copy one `PROJECT CARD` block and fill in the title, description, tags (skills/tech), links, and screenshot. Keep the same format so every project reads consistently.
